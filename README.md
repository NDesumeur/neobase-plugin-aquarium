# Aquarium

Garde en vie les poissons attrapés à la Pêche : bassins, nourriture, décors et visiteurs qui rapportent des pièces.

Ses données sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise). Au premier lancement, il reprend ce que tu avais déjà dans NeoDex.

Nécessite le plugin **Pêche** (installé automatiquement) : la sauvegarde est commune et se trouve dans son dossier.

## Installer

Dans NeoDex : **NeoStore → À découvrir → Aquarium → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
